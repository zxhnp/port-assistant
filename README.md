# 端口助手

Windows 和 macOS 串口、UDP 和 TCP 收发工具。使用 Vue 3、TypeScript、Vite、shadcn-vue 和 Tauri 2，桌面通信由 Rust 负责。

## 本地网页开发

需使用 Node.js 22.12 及以上的 22.x 版本和 npm。

```powershell
npm ci
npm run dev
```

若 npm 的默认缓存目录不可写，可改用 `npm ci --cache .npm-cache`。

打开 [本地网页](http://127.0.0.1:1420/)。Windows 本地开发预览会列出系统登记的串口，点击「刷新串口」可重新枚举。点击连接时会检查串口是否能打开、UDP / TCP 服务端本地地址是否能绑定，或 TCP 客户端能否连接对端。检查结束后立即释放端口，网页进行模拟收发和置顶。在网页中连接成功后，配置区和页脚显示「模拟连接」或「模拟监听」。用虚拟串口对验证时，请在桌面程序打开接收端（如 COM2），在另一程序打开配对的发送端（如 COM1），保持两端串口参数一致。

```powershell
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --locked -p port-transport
```

Rust 本机测试需要当前 Rust 工具链、MSVC 链接器和 Windows SDK。测试覆盖拆帧、UDP/TCP 本机回环、TCP 客户端隔离和目标断线停发。

## 收发

- 左侧选择协议、配置参数并打开连接。TCP 服务端开始监听后，在「发送目标」里选定客户端。
- UDP 支持单播、IPv4 广播和 IPv4 组播。广播填写目的广播地址和端口。组播填写组播地址、本地地址、本地端口和目的端口。组播使用本地地址对应的网卡，本地地址为 0.0.0.0 时由系统选择网卡。组播 TTL 可设置为 0～255，默认 255。接收端口应与发送目的端口一致。
- 串口默认使用 9600 波特率，支持无校验、奇校验、偶校验、标记校验和空格校验。收发两区默认使用TXT模式。
- TXT发送使用 UTF-8。HEX 可直接输入连续字节，也可用空格和换行分隔。实际发送预览包含启用的帧头和帧尾。
- 帧头和帧尾支持 HEX 或 UTF-8 TXT。TXT支持直接输入 Unicode 字符，也支持 \\u0001、\\u001、\\u{1}、\\r、\\n、\\t 和 \\\\ 转义。HEX 与TXT各自保留输入值。
- 串口和 TCP 按字节流拆帧。第一处匹配的帧尾结束该帧，半帧等待下一次读取。UDP 每个数据报独立处理。关闭「接收按帧拆分」可查看原始读取结果。
- 「暂停」冻结日志显示，继续后显示缓存。点击日志行查看内容或帧详情。每次发送最多 1 MiB，UDP 最多 65507 字节。日志保留最新 2000 条且最多 8 MiB 原始数据。
- 定时发送固定启动时的内容和目标。断开、选定目标掉线或写入失败时自动停止。
- TCP 客户端可选自动重连，默认关闭，间隔默认 3000 毫秒。连接失败或断线后按间隔重试，点击「停止重连」结束重试。重连成功后需手动重新启动定时发送。

## 桌面安装包

仓库的 **Actions → 桌面安装包 → Run workflow** 手动触发构建。从运行页下载对应的构建产物：Windows 10/11 x64 提供 NSIS（`portAssistant_<版本>_x64-setup.exe`）和 MSI；macOS 提供 Apple Silicon 和 Intel 两种 DMG。Windows 缺少 WebView2 时安装程序会下载引导程序。

安装包未配置代码签名和 Apple 公证，系统可能提示未知发布者或阻止直接打开。macOS 的 Mark 和 Space 串口校验暂不支持。点击标题栏的“打开新窗口”可以启动独立实例；各实例不能同时独占同一个串口或本地端口。

Windows 首次安装的默认目录名为 `PortAssistant`，安装标题和快捷方式仍显示“端口助手”。已安装版本升级时会沿用原安装目录。`src-tauri/installer` 中的安装器模板基于 Tauri CLI 2.12.5；升级 Tauri CLI 时需与对应版本的默认模板比较并同步更新。

安装后可用 TCP/UDP 本机回环、实体串口或虚拟串口对验证真实通信。将窗口置顶后切到另一个应用，可核对窗口层级与取消置顶行为。
